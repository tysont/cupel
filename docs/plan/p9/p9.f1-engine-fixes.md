# P9.F1 — Follow-up fixes: the mutation score, the suite cache, the mutation slots, aliased imports

Branch `p9-engine-fixes`. Read `common.md` first, then the plan's `#### P9 Notes` bullet **P9 — follow-up list**, items (16), (17), (19), and (20), and the ADRs each names. ADR number: **141** (one ADR covering the four decisions, one section each; the items it closes are struck from the follow-up list in the plan with a pointer to it).

## (16) Uncovered mutants count against the score

`tests.mutation.score` is `killed / (killed + survived)`, "1 when nothing was scored". A mutant no test runs (`uncovered`) is left out, so a change whose sites no test reaches scores 1.0 and passes `tests.mutation.score >= 0.80` (ADR-129 §5 kept the convention when the combining bug was fixed). Decide and record: the score is `killed / (killed + survived + uncovered)`; a scope with no mutant at all (nothing to mutate) stays 1. This is what PIT, mutmut, and cargo-mutants report (a mutant nothing tests is a missed mutant). Every mutation golden holds uncovered sites, so their `score`, `metrics.score`, and any survey rank built on them move; list each changed value in the notes with the before and after, and confirm with `git diff` that nothing else in those goldens changed. The `describe` summary and the metric's description say the new formula. Rerun the P9.1 gate test `a_changed_mutation_rule_against_base_reruns_the_suite_at_the_base_commit` and restore its original first phase if it now holds (an uncovered change scores 0.0): see the P9.1 tests note. Cupel's own changed gate measured 0.958 (23 of 24) at P9.0; measure the tree's uncovered count and say what the rule should be if it no longer holds 0.80.

## (17) A failed suite run is not reused from the cache

P9.2 found that a baseline suite run that failed for an environment reason (disk full) was cached under `.cupel/cache/suite` and reused on later runs until deleted. Find where suite results are cached and keyed; decide and record: a suite result whose status is not `pass` is never reused (it is rerun next time), or, if a failed result is worth keeping for `baseline.test-failed` findings, it is reused only while the tree and the environment are unchanged and never after an `error`/no-exit-code outcome. Prove it with a test that runs the real binary twice against a fixture whose suite fails once (a test that reads a file you remove between runs) and passes the second time.

## (19) Mutation slots are reclaimed

Slot directories (`overlay.rs`: `$TMPDIR/cupel-mutate/<hash of the repository path>/<lang>/<n>`) persist by design for incremental builds (ADR-082) and are never reclaimed: four slots per repository path, each a workspace build (~13 GB for Cupel); two finished runs held 87 GB and filled the owner's disk twice, and a deleted worktree's slots stay forever. Decide and record a reclamation rule that keeps incremental builds for the repository being graded: at the start of a mutation run, remove every slot directory whose repository path no longer exists, and remove slots of other repositories not used for N days (pick N and justify) or beyond a total size; at the end of a run that was stopped by the budget or cancelled, leave the slots in a consistent state. Add a `cupel doctor` line that reports the slots' total size and which repositories they belong to (store the repository path in a marker file in each slot root so the hash can be mapped back). Tests on the real engine with fixture repositories in temporary directories.

## (20) An aliased ES import binds its alias

`References` (ADR-135) resolves an ES import by `ImportEdge.names`, the imported names ADR-133 records (`import { square as side }` → `square`), so uses of `side` stay unresolved. Capture the local binding too (the ecma `imports.scm` has the alias node; add `ImportEdge.bindings`, or a `(imported, local)` pair, additively) and bind the local name in `references.rs`; the Python `from x import a as b` case gets the same. Fixture: the existing `import { square as side }` in the JavaScript fixture plus a Python alias; the references goldens gain the resolved uses.
