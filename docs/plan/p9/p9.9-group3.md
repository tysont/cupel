# P9.9 group 3 — one TypeScript, one Clojure

Branch `p9-dogfood-ts-clojure`. Read `common.md`, then `p9.9-external-dogfood.md`, then ADR-138 (the method, the selection criteria, the triage rubric; group 1 wrote it), then `docs/dogfood/spf13-cobra.md`, the shape every report takes. The owner cut this group to **one repository per language**: one TypeScript, one Clojure.

## What you do

1. Select one TypeScript and one Clojure repository by ADR-138's criteria. `survey` and `check --depth deep` on each with the branch's binary; triage every finding; a false positive is a check bug with a fixture case first, the fix, goldens additive, the repository rerun; reports `docs/dogfood/<owner>-<repo>.md`.
2. The plan: `**P9.9 — group 3**` bullet with the per-repository rates and the fixes.
3. `make check`, `make parity` if you touched the CLI or the envelope, `make dogfood` on the branch.

Every run of a repository's suite (its documented test command, `cupel survey`, `cupel check`) goes through `scripts/heavy.sh`, the machine-wide lock: one heavy command on the machine at a time; another group runs beside you.

## Leave alone

The rubric of ADR-138 (amend only with a reason recorded there). Nothing in the gate, the renderers, or the daemon.
