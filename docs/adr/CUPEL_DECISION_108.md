# CUPEL_DECISION_108: Java: grammar, syntactic facts, test conventions, the Maven and Gradle toolchain, and mutation through PIT

**Date:** 2026-10-17 · **Status:** accepted · **Phase:** P6.4

## Context

P6.4 adds Java as the sixth language by following design §8.4.4 verbatim: a grammar crate, `langs/java/` with queries, tables, and the hand-written `ModuleGraph` and `ProjectInfo` producers, a fixture repository whose `inventory.toml` maps every construct of every fact inventory, a toolchain-table row, and every golden the matrix test demands. ADR-038 already recognized Maven and Gradle roots as `java` without registering the language. The design says only that Java mutation goes through PIT as a producer plugin (§8.3.8, §8.4.3) and that JaCoCo can give per-test coverage (§8.7). Everything below is a choice the design leaves open: what each fact means for Java's constructs, which tools the row lists and how they run, and where PIT plugs in.

## Options

**Grammar.** `tree-sitter-java` 0.23.5 is the only maintained Rust grammar crate; it depends on `tree-sitter-language` only, and its parser is ABI 14, which tree-sitter 0.27 reads.

**Functions and visibility.** Every named Java function is a method, so `symbols.function` is either not applicable or stretched to static methods. Java has four access levels for three `Visibility` values: `public`, `protected`, package-private, and `private`. `protected` members are visible to subclasses in other packages, so they are part of what a subclass compiles against; package-private members are visible throughout the package, which is what `internal` means (ADR-032).

**Namespaces.** The package clause names a file's namespace, as Go's does, and each type scopes its members. Alternatives were path-derived namespaces (`src/main/java/` stripped), which disagree with the package for files outside the conventional layout.

**API surface.** Public items of public types only, or every public member. A public method of a package-private class is unreachable from outside the package, so it is not API. A signature could include modifiers (`static`, annotations), or just the result type, name, parameters, and `throws` clause.

**Tests.** JUnit 5 (Jupiter) and JUnit 4 share the `@Test` annotation name; jqwik's `@Property` methods are property tests (ADR-095). Assertions come from JUnit's `Assertions`/`Assert` (static, often imported statically), AssertJ's fluent chains, Mockito's `verify`, and java-snapshot-testing's `toMatchSnapshot`.

**Module graph.** An import names a type, not a file; the file depends on the source roots. Roots could come from build files (Maven `<sourceDirectory>`, Gradle source sets), which needs build-file evaluation, or from the files themselves: a file's package declaration tells where its root is. Same-package references need no import at all.

**Runners.** Maven Surefire and Gradle both write JUnit XML (`TEST-*.xml`), one file per test class, into a directory the run does not clean. The JUnit parser exists (pytest, nextest). A runner could read the default report directory (stale files from earlier narrowed runs survive there), or point the tool at a fresh directory of its own under `.cupel/`.

**Coverage.** JaCoCo writes XML whose `<sourcefile>`s are named `<package>/<File>.java`; the parser exists (P3.2). It writes to a fixed directory per build tool (`target/site/jacoco/jacoco.xml`, `build/reports/jacoco/test/jacocoTestReport.xml`), not to a path Cupel names. Maven can run JaCoCo's goals by coordinate without a `pom.xml` change; Gradle needs the `jacoco` plugin applied in the build.

**Mutation.** The design names PIT through a producer plugin. The native engine (`engine.mutation`, `Langs::Any`) could also mutate Java by file copies and reruns of the Maven runner. With both registered, the native producer wins every selection (ADR-088 §7), and only `TestResults` had a pin key.

## Decision

1. **Grammar and identity.** Workspace dependency `tree-sitter-java = "0.23.5"`. Language `java`, family `java`, extension `.java`, stability `experimental`, one grammar.
2. **Symbols.** Methods (static ones too), constructors, and a record's compact constructor are `method`s, namespaced by the package clause (`@namespace.name`) and each enclosing class, interface, enum, record, or annotation type (`@scope`); separator `.`. A lambda assigned to a local variable or a field is a `closure` named by the variable. `private` is `private`; `public` and `protected` are `public`; package-private is `internal` (`[visibility] default`); an interface's methods are `public` unless `private`. Parameters are formal and varargs parameters; the implicit `this` is not one. `symbols.function` and `symbols.nested-function` are not applicable. A file without a package clause takes its namespace from its path below the source set's `java` directory (`[namespace] source_roots = ["java"]`; `module-info` and `package-info` add no segment).
3. **Decisions.** `if` (branch; `else if` continues the chain: `chain_parents = ["if_statement"]`), `for`/enhanced `for`/`while`/`do` (loop), `&&`/`||`, `?:` (ternary), `catch`, `return` (early return), and each `case` group or `case` rule of a switch statement or expression (case; `default` is not). A for-each over an array or `List.of`/`Arrays.asList` written in place, or over a local declared from one in the same block, is a table loop (ADR-069).
4. **NormTree.** The table-driven normalizer: `identifier` and `type_identifier` become `$id`, Java's literals `$lit`, `modifiers` (annotations included) are erased, and a `method_invocation`'s `name` and an `object_creation_expression`'s `type` keep their text.
5. **Mutation sites.** The operator tokens, `true`/`false`, integer literals, statements directly in a block or switch group evaluated for their effect (calls, assignments, increments), returned references (replaced by `null`: a mutant returning `null` from a method of primitive type does not compile, and the engine reports it unviable), integer constants, compared literals moved by one, and the conditions of `if`, `while`, `do`, and `for` negated as `!(…)`.
6. **Tests.** Cases are methods annotated `@Test`, `@ParameterizedTest`, `@RepeatedTest`, `@TestFactory`, `@TestTemplate`, or jqwik's `@Example`; `@Property` methods are cases with property framework `jqwik`, and a property returning `boolean` asserts its result. The framework is `jqwik`, `junit5`, or `junit4` by the file's imports (default `junit5`). Assertions are keyed by method name: JUnit's (`assertEquals` strong equality, `assertNotEquals` weak, `assertTrue`/`assertFalse`/`fail` weak truthiness, `assertNotNull`/`assertDoesNotThrow` weak not-null, `assertThrows` strong throws, `assertNull` strong equality), JUnit 4's `@Test(expected = …)` (strong throws), AssertJ's first matcher after `assertThat(…)` (`isEqualTo` strong, `isNotEqualTo` weak, …) and `assertThatThrownBy` (strong throws), `toMatchSnapshot` (snapshot), and Mockito's `verify` (custom). Mocks are `mock(X.class)`/`spy(…)` (target `X`) and fields annotated `@Mock`/`@Spy`/`@MockBean` (every case in the file). Skips are `@Disabled`/`@Ignore` with their reason; setup is any lifecycle method (`@BeforeEach`, `@BeforeAll`, `@AfterEach`, `@AfterAll`, JUnit 4's `@Before`/`@BeforeClass`/`@After`/`@AfterClass`, jqwik's `@BeforeProperty`/`@BeforeContainer`).
7. **Test conventions.** Everything under `src/test/` (at any depth) is test code. A source `…/src/main/java/<package>/<Name>.java` is tested by `…/src/test/java/<package>/<Name>Test.java` or `<Name>Tests.java` anywhere in scope (a glob, so multi-module trees pair too). Inline tests are not applicable.
8. **API surface.** Public types (`class`, `enum`, `record` as `type`; `interface` and `@interface` as `interface`); public and protected methods and constructors of public classes, enums, and records; methods of public interfaces unless `private`; `public static final` fields and interface constants as `constant`, other public and protected fields as `variable`; the constants of public enums; a `module-info.java` module as `module`. A method's signature runs from its type parameters or result type through its `throws` clause (`void deposit(long _)`), parameter names local. `function` is not applicable.
9. **Roots.** `public static void main(String[])` is an entry point; methods annotated `@Override`, `@PostConstruct`, `@PreDestroy`, `@Bean`, or a lifecycle annotation are framework hooks, as are the serialization hooks named in `[roots]` (`readObject`, `writeObject`, `readResolve`, `writeReplace`).
10. **Module graph** (`langs/java/resolve.rs`). Source roots are each file in scope's directory with its package path removed, plus every `src/<set>/java` directory of the repository (searched six levels deep, skipping hidden and build directories). A type import names the file of its outermost type in some root (the longest prefix of the name that is a file, so static and nested imports resolve); an import on demand names every Java file of the package directory. The JDK (`java.`, `javax.`, `jdk.`, `sun.`, `com.sun.`, `org.w3c.dom`, `org.xml.sax`, `org.ietf.jgss`) is `External` package `jdk`. Another name is `Unresolved` when a prefix of its package is a package the repository declares, else `External` with its package (the segments before the first capitalized one). Edges group by the nearest directory with a Maven or Gradle build file. Same-package references are not edges: `static.dead-code` treats a package as one module (ADR-058 §1), so they do not matter there. `relative`, `declaration`, and `re-export` are not applicable.
11. **Project info.** `pom.xml`, `build.gradle(.kts)`, and `settings.gradle(.kts)` mark roots, with nested build files as members; `target`, `build`, and `.gradle` are generated; no package patterns. The ecosystem moves from `langs/ecosystems.rs` to `langs/java/project.rs`.
12. **Runners.** `tool.maven` (detected by `pom.xml`): `mvn -B --no-transfer-progress test -Dsurefire.reportsDirectory=<dir> -Dsurefire.failIfNoSpecifiedTests=false`, where `<dir>` is a directory under the runner's `.cupel/cache/runners/` area that the command clears before each run; narrowing is `-Dtest=<Class>#<method>+<method>,…` for tests and the classes of test files; listing is not supported. `tool.gradle` (detected by a Gradle build or settings script): `gradle test --rerun --console=plain` with an init script in the runner's area pointing every `Test` task's JUnit XML at its fresh directory; narrowing is `--tests <Class>.<method>`. Both read every `TEST-*.xml` with the JUnit parser. A test's ID is `<class>#<method>` (Gradle's `()` dropped), its file `src/test/java/<class path>.java` when that exists. Seeded runs pass Surefire's random run order and JUnit Jupiter's random method orderer with the seed (Maven) or the Jupiter orderer alone (Gradle); the reports give the order (ADR-078).
13. **Coverage.** `tool.jacoco-maven` runs `mvn -B --no-transfer-progress org.jacoco:jacoco-maven-plugin:0.8.13:prepare-agent test org.jacoco:jacoco-maven-plugin:0.8.13:report` (no `pom.xml` change) and reads `target/site/jacoco/jacoco.xml`; `tool.jacoco-gradle` runs `gradle test jacocoTestReport --console=plain` and reads `build/reports/jacoco/test/jacocoTestReport.xml`, which needs the build to apply the `jacoco` plugin with XML reports on. Each report's `<package>/<File>.java` names are placed below the root's `src/main/java` (the first source root that has the file). JaCoCo measures branches. A multi-module build's per-module reports are not aggregated (open item). No `PerTestMap` producer is registered: `tests --impacted` falls back to `ModuleGraph` impact for Java.
14. **Mutation.** `MutationOutcomes` for Java comes from the PIT producer plugin (ADR-110), selected by `[lang.java] mutator = "plugin.pit"`, a new pin key (`FactKind::pin_key` for `MutationOutcomes`). Without the pin the native engine still serves Java by file copies through the selected runner; `tests.mutation` is unchanged either way.
15. **Not produced.** No property engine framework for jqwik, no differential harness, no analyzers, and no footprint reader are registered for Java in P6.4, so `gen.property`, `gen.differential`, `static.analyze`, and `perf.footprint` are `unsupported` for Java with their missing fact as the reason (P6 Notes).

## Consequences

- Java joins every syntactic check through queries and tables alone, with two small hand-written producers (`ModuleGraph`, `ProjectInfo`); the conformance suite, `describe language java`, and the matrix test cover it like the five launch languages.
- `init` now writes Maven and Gradle roots into `[roots]` with the runner's command; `init.unsupported-root` has no ecosystem left to report (ADR-110).
- A mutation run through PIT reports PIT's own mutators mapped onto Cupel's sites; a project can still pin the native engine (`mutator = "engine.mutation"`) to use Cupel's operator tables.
- Signatures print `long[][]` as `long[] []`; the spacing rules are shared by every language and a `tight_after` entry for `]` would glue `]` to a following name.
- Open: jqwik in the property engine (its seed and try-count flags exist: `-Djqwik.seeds.whenfixed`, `@Property(tries)`), JaCoCo per-test sessions for a `PerTestMap`, `javac -Xlint` or Error Prone as analyzers, a `pom.xml`/Gradle lockfile footprint reader, aggregated multi-module coverage, and listing tests without running them.
