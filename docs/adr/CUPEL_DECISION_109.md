# CUPEL_DECISION_109: Clojure: the grammar, what each syntactic fact means in a Lisp, and the Clojure CLI toolchain

**Date:** 2026-10-17 · **Status:** accepted · **Phase:** P6.4

## Context

Clojure is the seventh language, added by design §8.4.4 like Java (ADR-108). Unlike the six before it, its syntax has no statements, operators, or declarations: every form is a list whose first element says what it is, and `defn`, `if`, `<`, and `deftest` are all symbols in that position. Every fact inventory was written with C-family constructs in mind, so each needs a reading in Clojure terms: what a symbol, a decision, a mutation site, a test case, a public item, a module, and a project are. ADR-038 already recognized `deps.edn` roots as `clojure`. The toolchain row must name a runner and Cloverage (plan P6.4), neither of which writes the reports the existing runners read.

## Options

**Grammar.** Two crates on crates.io: `tree-sitter-clojure` 0.1.0, which depends on `tree-sitter` 0.25 itself (a second tree-sitter in the build, whose `Language` type the workspace's 0.27 cannot take), and `tree-sitter-clojure-orchard` 0.2.8, grammar-orchard's maintained fork of sogaiu's grammar, which depends only on `tree-sitter-language` and generates an ABI-14 parser that tree-sitter 0.27 reads. Both are deliberately "minimal": lists, vectors, maps, symbols, keywords, and literals, with no special forms; and in the orchard grammar comments are ordinary named nodes, not extras.

**Matching forms.** Queries can match a list by its head symbol's name (`(sym_lit name: (sym_name) @_d)` with `#eq?`), but cannot pair the flat clauses of `cond` or `case`; positional patterns with anchors can, up to a fixed count. The alternative is hand-written producers for decisions and mutations.

**Normalization.** A call's function is its list's first element. The `[normalize]` table can keep a callee's text only for a field, and every element of a list is in the same `value` field, so the table would erase `+` and `-` alike and `(f x)` would hash like `(g x)`.

**Runner.** `clojure.test` has no report format of its own beyond `clojure.test.junit/with-junit-output`; Kaocha has a JUnit plugin but is a dependency the project must declare; cognitect's test-runner prints text only. Leiningen projects (`project.clj`) need `lein`, a different tool.

**Coverage.** Cloverage writes LCOV with `--lcov` (paths relative to the project) to `target/coverage/lcov.info`; it can be added for one run with `-Sdeps` instead of an alias in `deps.edn`.

## Decision

1. **Grammar and identity.** Workspace dependency `tree-sitter-clojure-orchard = "0.2.8"`. Language `clojure`, family `clojure`, extensions `.clj` and `.cljc`; ClojureScript (`.cljs`) runs on another platform and is not claimed. Stability `experimental`.
2. **Symbols.** `defn`, `defn-`, and `defmacro` define functions; `deftest` and `defspec` too (a test is a var holding a function the runner calls, so tests are symbols as Go's are). `letfn` functions are nested functions; a `fn` bound by `def` or in a binding vector (`let`, `loop`, `with-redefs`, …) is a closure named by its binding, and the closure's node is the `fn` form. Methods are the protocol and interface methods `defrecord`, `deftype`, and `extend-type` implement, namespaced by the record or type (an `@scope.name` in the match), and `defmethod` implementations, named for their multimethod. The `ns` form names the namespace; the separator is `/`, so a var reads `ledger.core/balance`. Visibility: `defn-` and `^:private`/`^{:private true}` metadata are `private`, other vars `public` (`[visibility] modifiers` keyed by the defining symbol); Clojure has no package level, so `internal` is not applicable, and neither is `static-method`. Parameters are the elements of a single-arity function's own parameter vector (a destructuring map or vector counts once, `&` not at all) and of a method's after its receiver; a multi-arity function's parameters are not counted, and an anonymous `fn` passed inline belongs to the function whose body it is in.
3. **Decisions.** `if`, `if-not`, `if-let`, `if-some`, `when`, `when-not`, `when-let`, `when-some`, `when-first` are branches; each test of a `cond` (not `:else`) is a branch, siblings of one list and so not nested in one another, which is Clojure's else-if; each test constant of a `case` and each test of a `condp` is a case; `loop`, `doseq`, `dotimes`, `while`, `for` are loops; `and`/`or` are boolean operators; `catch` is a catch. Clauses are matched by position, up to twelve per form (a comment between clauses ends the count, since comments are nodes here). A `doseq` or `for` over a vector of vectors written in place is a table loop. `early-return` and `ternary` are not applicable: there is no return, and `if` is the conditional expression.
4. **NormTree** (hand-written, `langs/clojure/normalize.rs`). Every form keeps its shape; the head symbol of a list keeps its name (`+`, `str/join`); other symbols and keywords become `$id` (map keys are field names); numbers, strings, characters, regexes, booleans, and `nil` become `$lit`; comments, `#_` discards, metadata, and the definition's own name are dropped.
5. **Mutation sites.** An operator site is the head symbol's name: `<` `<=` `>` `>=` (relational), `=` `not=` `==` (equality), `+` `-` `inc` `dec` (add/sub), `*` `/` (mul/div), `and` `or`; `true`/`false`; `0`/`1`; a call that is not the last form of a `do`, a `let`-like body, a `when` body, or a single-arity function (statement deletion); a single-arity function's last form replaced by `nil` (return value); other numbers replaced by `0`; a number compared against moved by one (`(inc n)`, `(dec n)`); and the test of `if`, `if-not`, `when`, `when-not` wrapped in `(not …)`. Site hashes count comment nodes as siblings, so a comment added inside a function moves its sites' hashes.
6. **Tests.** Cases are `deftest`s (framework `clojure-test`) and test.check `defspec`s (property framework `test-check`; a `prop/for-all` asserts its body for every generated input, ADR-095). Assertions are `is` forms keyed by the predicate they test (`=` and `nil?` strong equality, `not=` weak equality, `some?` and `(not (nil? …))` weak not-null, `thrown?`/`thrown-with-msg?` strong throws, a bare `(is x)` weak truthiness) and `are` templates. Doubles are the vars `with-redefs` rebinds (the first three bindings by position). Setup is `use-fixtures`. clojure.test has no skip marker and no snapshot assertion: `skip` and `assertion-snapshot` are not applicable.
7. **Test conventions.** Everything under a `test/` directory is test code; `src/<ns path>.clj` is tested by `test/<ns path>_test.clj` (`{base}test/{module}_test{ext}`, `source_roots = ["src", "test"]`), so members' trees pair too. Inline tests are not applicable.
8. **API surface.** Public `defn`/`defmacro` (`function`, signature the single-arity parameter vector with names local, `[_ & _]`), `defprotocol`/`definterface` (`interface`) and their method signatures (`method`), `defrecord`/`deftype` with their fields (`type`), `^:const` `def`s (`constant`), other `def`s and `defonce`s (`variable`); `^:private` vars are left out. `module` is not applicable: the `ns` form names the namespace of what follows, as Go's package clause does.
9. **Roots.** `-main` is an entry point (`[roots] entry_points`); `defmethod` implementations and the methods records and types implement are framework hooks (called by dispatch).
10. **Module graph** (`langs/clojure/resolve.rs`). Imports are the libspecs of an `ns` form's `:require` and `:use` (`[a.b :as c]` or bare `a.b`) and the packages and classes of its `:import`. Source roots are each file's directory above its namespace's path, plus the `:paths` and `:extra-paths` of every `deps.edn` (default `src`). A namespace `a.b-c` is `a/b_c.clj` or `.cljc` in a root. `clojure.*` is `External` package `clojure`; `java.`/`javax.`/`jdk.` names are `External` package `jdk`; another namespace is `Unresolved` when a prefix of it is a directory of Clojure files in a root, else `External` with the namespace as package. Edges group by the nearest directory with a `deps.edn`. `relative`, `declaration`, and `re-export` are not applicable.
11. **Project info.** `deps.edn` marks a root, nested `deps.edn` directories (`:local/root` dependencies) are members, `target` and `.cpcache` are generated, no package patterns. The ecosystem moves from `langs/ecosystems.rs` to `langs/clojure/project.rs`. Leiningen's `project.clj` is not recognized (open item).
12. **Runner** `tool.clojure-test`. The Clojure CLI with the `:test` alias (the CLI only warns when a project does not declare it) runs Cupel's runner script (`cupel-adapt/src/clojure_test.clj`, written to the runner's `.cupel/` area): it loads every `*_test.clj(c)` namespace in a classpath directory, or the vars and files named after the report path, runs them through `clojure.test` (fixtures included) with `clojure.test.junit` output bound to the report file, and exits 0 only when nothing failed. Test IDs are vars, `<namespace>/<name>`; files are found below `test/` or `src/`. It lists tests (`--list`) and takes an explicit order: named tests run in the order given, and a shuffled run passes `--seed`, which the script shuffles with.
13. **Coverage** `tool.cloverage`, format LCOV: `clojure -Sdeps '{:deps {cloverage/cloverage {:mvn/version "1.2.4"}}}' -M:test -m cloverage.coverage --src-ns-path src --test-ns-path test --lcov --no-html --no-summary`, report `target/coverage/lcov.info`. Cloverage measures forms by line and no branches; it exits non-zero when a test fails, which is `coverage.run-failed` as for every coverage tool.
14. **Mutation.** The native engine serves Clojure by file copies through the runner; no Clojure-specific schemata.
15. **Not produced.** No property engine framework for test.check, no differential harness, no analyzers (clj-kondo is the candidate), no footprint reader, and no `PerTestMap`: `gen.property`, `gen.differential`, `static.analyze`, `perf.footprint` are `unsupported` for Clojure, and `tests --impacted` falls back to module impact.

## Consequences

- Every syntactic check runs on Clojure from queries plus one hand-written normalizer, and the conformance suite proves each construct or records why it does not apply.
- Positional clause patterns are a fixed-size approximation: a `cond` or `case` longer than twelve clauses undercounts, and a comment between clauses stops the count. A hand-written decisions producer would remove both limits.
- `(if a x (if b y z))` nests its inner `if` (nesting 1): the else-if chain rule is by parent node kind, and every form here is a list. Idiomatic code writes `cond`.
- Tests are symbols, so they appear in `static.complexity` and `static.dead-code` as Go's do (roots by reason `test`).
- Open: Kaocha's runner and its JUnit plugin, Leiningen, multi-arity parameter counts and signatures, test.check in the property engine (`quick-check` takes a seed and a trial count), clj-kondo as an analyzer, a `deps.edn` footprint reader.
